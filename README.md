# RiskCalc Mobile App

Starter project aplikasi mobile Android native untuk RiskCalc.

## Stack

- Kotlin
- Jetpack Compose
- Material 3

## Fitur awal

- Form input:
  - usia
  - tekanan darah sistolik
  - kolesterol total
  - status merokok
- Tombol prediksi
- Area hasil prediksi

## Struktur

- `app/` -> modul Android utama
- `app/src/main/java/com/riskcalc/mobile/` -> source code utama
- `app/src/main/java/com/riskcalc/mobile/ui/theme/` -> tema Compose

## Catatan

Project ini masih starter structure. Integrasi FastAPI dan engine Perceptron akan kita sambungkan di langkah berikutnya.

## Next step

1. Buka folder `mobile-app` di Android Studio.
2. Sinkronkan Gradle.
3. Hubungkan HP Android via USB Debugging.
4. Jalankan app ke device fisik.
